# User guide and demonstration

## Member journey
1. Open the home page; select Join the community.
2. Enter name, unique email, interests and a strong confirmed password.
3. Sign in. The dashboard displays your own progress, not a static mock-up.
4. My profile → edit your bio/interests and upload a photo under 2 MB.
5. Events → save a place. Registering again is rejected. Cancel if needed.
6. Learning library → search/filter, open a learning link, mark it completed. Return to Overview to see updated progress.
7. Community → start a conversation and reply. Content is displayed as text, not executable HTML.
8. Mentorship → request guidance from a mentor. The request appears under Your connections.
9. Sign out using the sidebar form. Direct dashboard access redirects to login.

## Eight innovation journeys
1. **Discover:** inspect genuine public milestones; add/remove a cheer. No private solution text appears here.
2. **Daily challenge:** read today’s prompt, submit code or a written approach, revise until approved. Administrator reviews manually. Never execute an untrusted submission.
3. **Milestones:** view current/best streak and earned badges. Visits, logins and cheers do not earn practice days.
4. **Project lab:** publish a title, description and optional HTTP(S) link. Another member leaves feedback; owner receives an inbox alert. Owners/admins can delete projects; admins moderate feedback.
5. **Calendar:** navigate month, inspect workshop dates and countdowns; register through Events.
6. **Search:** find members, workshops, resources, discussions and projects. Private submissions, inbox and emails are excluded.
7. **Inbox:** review own alerts and mark individual/all messages read. Reminders are generated on app opening within 48 hours of a registered event; no email/push is sent.
8. **Theme:** switch light/dark. Preference persists on this browser. OS reduced-motion preference suppresses decorative animation.

## Safe update on an already populated Windows installation
Export the database and back up the folder first. Copy updated application files while keeping config.local.php and uploads. Start XAMPP MySQL, run upgrade-windows.bat, then refresh the existing localhost address. Do not run the fresh installer or import the base schema over existing records. Actual Windows execution must be checked on your machine.

## Mentor journey
An administrator assigns a real account the mentor role. The mentor signs in with their own password, visits Mentorship and accepts/declines requests addressed to them. After acceptance, use the community board for learning discussions; private messaging/video appointments are not implemented.

## Administrator journey
Administration offers role/status changes, event and resource publish/edit/delete forms, topic removal, participant attendance and recent activity. Download engagement CSV to review registrations, attendance, resources and discussion counts. Download event CSV for capacity/registrations/attendance. Exports contain member emails: keep them private.
